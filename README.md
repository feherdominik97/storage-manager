# Laravel Storage Management System

A simple Laravel-based storage management system that lists and categorizes different types of storage.

## 🚀 Features
- Manage **categories** and **products**
- Display products based on **storage type**
- Uses Laravel configuration for filtering

## 🛠️ Installation
```sh
git clone https://github.com/feherdominik97/storage-manager.git
cd storage-manager
composer install
php artisan migrate --seed
php artisan serve
```

Visit `http://127.0.0.1:8000` in your browser.
